# PowerBrowser
A Powerfull Web Browser using PyQt6

## About
PowerBrowser is a personal 9th Grade Project Idea. It is not meant for personal use, please do not send pull requests, you may send issues with the code. If you desire, you may use this browser. This browser will be updated every month, hence the next update will be on Mid-December

## Capabilities of the Browser
- Has tabbed web-browswing
- Contains robust security
- Is able to upload and download to and from sites
- Can load almost all websites
- Has a clean UI with light and dark mode
- History and bookmark containing support
- SQL Database Connection
- Note-taking ability
- Reading Various Types of Documents
- Has an istant search feature
